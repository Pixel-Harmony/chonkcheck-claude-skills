# Dashboard Copy Refinement - Format Example

> Fictional example showing copy refinement format for a single page.

## Executive Summary

**Source**: Dashboard UX design
**Tone**: Friendly, encouraging, efficient
**Key Changes**: Added personality to empty states, made CTAs action-oriented

---

## Copy Refinement

| Element | Before | After | Rationale |
|---------|--------|-------|-----------|
| Greeting | "Hello, [Name]" | "Hi, [Name]!" | More casual, exclamation adds warmth |
| Subheading | "Dashboard Overview" | "Here's your day" | Conversational, personal |
| Empty state | "No entries found" | "Nothing logged today. Start tracking!" | Encouraging, suggests action |
| Quick action | "Add" | "Log Food" | Specific action |
| Summary label | "Remaining Calories" | "Remaining" | Shorter, "cal" shown separately |

---

## Copy Inventory

### Headers
- **Greeting**: Hi, [Name]!
- **Subheading**: Here's your day

### Summary Card
- **Heading**: Today's Summary
- **Remaining**: Remaining: [X] cal

### Quick Actions
- **Button 1**: Log Food
- **Button 2**: Log Weight

### States

| State | Copy |
|-------|------|
| Empty | Nothing logged today. Start tracking! |
| Over goal | [X] cal over goal |
| Loading | Just a sec... |
| Error | Hmm, we couldn't load your diary. Try refreshing? |

---

## Tone Notes

- **Overall**: Friendly, efficient (70% conversational, 30% functional)
- **Empty state**: Encouraging without pressure
- **Errors**: Helpful, solution-focused

---

## Alternative Options

**Greeting alternatives**:
- "Hi, [Name]!" (recommended - warm, personal)
- "Welcome back, [Name]" (formal, good for returning users)
- "Good morning, [Name]" (time-aware, requires logic)

**Empty state alternatives**:
- "Nothing logged today. Start tracking!" (recommended)
- "Your diary is empty. Add your first meal!"
- "No entries yet. What's for breakfast?"
