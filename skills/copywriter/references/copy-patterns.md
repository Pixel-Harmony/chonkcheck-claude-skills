# ChonkCheck Copy Patterns

Quick reference for common UI copy patterns.

---

## Buttons

| Type | Pattern | Good | Bad |
|------|---------|------|-----|
| Primary CTA | Verb-first, specific | Start Tracking, Save Recipe, Add Food | Submit, OK, Done |
| Secondary | Non-committal, clear | Cancel, Skip for Now, Maybe Later | Abort, Dismiss |
| Destructive | Clear consequence | Yes, Delete Food / Delete Recipe | Confirm, OK |
| Link buttons | Conversational | See what's cooking, Learn more | Click here |

---

## Forms

| Element | Pattern | Good | Bad |
|---------|---------|------|-----|
| Labels | Concise noun, sentence case | Food name, Serving size | Enter Food Name: |
| Placeholders | Real example with "e.g." | e.g., Chicken Breast | Type here |
| Help text | "We use this to..." | We use this to calculate your daily calorie needs | Required field |

---

## Error Messages

**Pattern**: [Friendly opener] [What went wrong] [How to fix it]

| Type | Good | Bad |
|------|------|-----|
| Field error | Please enter a number between 1 and 300 | Invalid input |
| Form error | Oops! Please fix the errors above and try again | Form submission failed |
| Network error | Hmm, we couldn't load your diary. Try refreshing? | Error 500 |
| Auth error | Your session has expired. Please sign in again | Token expired |

---

## Success Messages

**Pattern**: [What happened] [Brief positive reinforcement]

| Good | Bad |
|------|-----|
| Recipe saved! Nice work | Operation successful |
| Weight logged. You're on a roll! | Your request has been processed |
| Profile updated. Looking good! | Changes saved to database |

---

## Empty States

**Pattern**: [What's missing] [Encouraging next step]

| Good | Bad |
|------|-----|
| No recipes yet. Create your first one! | No results found |
| Your diary is empty. Add a meal to get started | No data available |
| No foods match "pizza". Try a different search? | 0 matches found |

---

## Loading States

| Duration | Good | Bad |
|----------|------|-----|
| < 2 sec | Just a sec... | Please wait |
| 2-10 sec | Reading that label... This takes about 30 seconds | Processing request |
| > 10 sec | This is taking longer than usual... | Loading... |

---

## Tooltips

**Pattern**: Brief explanation, no jargon, 1-2 sentences

| Good | Bad |
|------|-----|
| We use this to calculate your daily calorie needs | Required for BMR calculation formula |
| We'll use this everywhere—recipes, diary, weight logs | Utilized throughout the application |

---

## Headings

| Type | Good | Bad |
|------|------|-----|
| Page H1 | Welcome to ChonkCheck!, Your Foods | Dashboard, Main Page |
| Section H2 | About You, Daily Goals, Recent Activity | User Information, Configuration |

## Navigation

| Type | Good | Bad |
|------|------|-----|
| Primary nav | Diary, Foods, Recipes, Weight, Profile | Food Diary, My Foods |
| Settings | Edit Profile, Account Settings, Sign Out | User Settings, Logout |
